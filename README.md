Entry for the make.fun bounty
[One Line, Zero Use: The Useless Superpower Sprint](https://make.fun/c/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68)
($5 pot, top 3).

`main.py` writes a single original line (68 characters) describing a
hilariously useless superpower to `/output/entry.txt`:

> I can read minds, but only my own — and only the embarrassing parts.

Run it with `python3 main.py`; it writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
